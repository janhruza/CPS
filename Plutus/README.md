# Plutus
*"God of wealth."* - Wikipedia

## About Plutus
Plutus is a simple personal finance app that combines calculators and an expense tracker in one program.
The core logic is being developed as a standalone engine, which future front ends will reuse.

> **Disclaimer:** Plutus is a personal project. It is not audited financial software and is not financial advice. Verify important figures, such as loan payments, against your bank's documents before making decisions.

### User Interface
Currently, the UI is a terminal application.
A GUI application is planned for the future,
once the core engine is stable.

## Features
Plutus' main features are:
- Mortgage calculator
- Expense tracker
- Loan calculator (the mortgage calculator is built on it)

### Planned Features
Some features are in progress:
- Currency converter
